# Historical scoped updates

These are the prior interface, music-intelligence and remote-Pi update packages, retained as source/reference and for their regression fixtures. They are not the root installation path or a tested upgrade path from arbitrary older builds. Their old READMEs may use legacy names and installation-specific examples. For a new Pi, follow root README.md and install.py. For an existing Pi, keep a private backup and compare the exact source before choosing a historical patch.

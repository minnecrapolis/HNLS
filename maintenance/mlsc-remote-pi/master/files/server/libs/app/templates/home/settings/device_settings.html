Add GPIO string

Keep your existing GPIO21 string and add a separate string on GPIO10 — physical pin 19. Both follow the same music, with separate LED counts and Song Show settings.

Checking SPI output…

Prepare SPI and reboot before adding the string. SPI0 must be dedicated to the LEDs. Use external LED power, a shared ground and suitable data-level shifting. After adding, choose the new device in Song Show to adjust its colors and grouping.

Add remote Pi

LED03 generates the show; the remote Pi drives its own RGB string on GPIO21 — physical pin 40. Audio stays on LED03.

Install the receiver on the other Pi first. Connect both Pis to the same LAN. Wi-Fi timing can vary; lost connections turn the remote string off after one second.

Loading remote Pis…

After adding, select its device to change LED count, physical color order and brightness in Device Settings, or colors and section grouping in Song Show. Each Pi needs its own LED power and a ground shared with its local LEDs.

Mixed RGB / GRB ranges

Different physical strips can share one continuous data chain. Set the output’s default order normally, then override only the LED ranges wired in a different order. Counts and brightness are not changed here.

Name (optional)First LEDLast LEDActual order

Loading color-order ranges…

Numbers start at 1 and include both ends. Example: 601–650 is a 50-LED range. Ranges cannot overlap; gaps inherit the default. Parallel data branches repeat the same addresses, so they cannot be mapped independently. This editor supports normal configured RGB outputs, including the paired slave; Advanced Studio has separate line settings.

Add GPIO string

Keep your existing GPIO21 string and add a separate string on GPIO10 — physical pin 19. Both follow the same music, with separate LED counts and Light Show settings.

Checking SPI output…

Prepare SPI and reboot before adding the string. SPI0 must be dedicated to the LEDs. Use external LED power, a shared ground and suitable data-level shifting. After adding, choose the new device in Light Show to adjust its colors and grouping.

Add or manage another PiPair a remote Pi and its light string.
Add remote Pi

LED03 generates the show; the remote Pi drives its own RGB string on GPIO21 — physical pin 40. Audio stays on LED03.

Install the receiver on the other Pi first. Connect both Pis to the same LAN. Wi-Fi timing can vary; lost connections turn the remote string off after one second.

Loading remote Pis…

After adding, select its device to change LED count, physical color order and brightness in My Lights, or colors and section grouping in Light Show. Each Pi needs its own LED power and a ground shared with its local LEDs.

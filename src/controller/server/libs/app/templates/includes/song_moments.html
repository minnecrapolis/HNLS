Fine-tune this moment

Each active moment completely replaces automatic lighting on its selected LEDs, including the background between moving lights. Moments override the normal lit-LED limit. Each string’s configured brightness still applies. Song gaps remain black. If moments overlap, the later-created row takes priority. A larger seconds-per-cycle value moves more slowly.
